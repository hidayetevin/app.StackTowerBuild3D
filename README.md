# Stack Build Tower 3D

## Setup
```bash
npm install
```

## Development
```bash
npm run dev
```

## Build
```bash
npm run build
npx cap sync
```

## Run on Android
```bash
npx cap open android
```
(Requires Android Studio)

## Features
- **Hyper-casual Gameplay**: Stack blocks as high as possible.
- **Visuals**: Gradient shaders, particle effects, dynamic lighting.
- **Audio**: SFX and Ambient Music with mute toggles.
- **Progression**: Daily rewards, missions system.
- **Monetization**: AdMob (Banner, Interstitial, Rewarded).
- **Analytics**: Firebase Analytics integration.
- **Performance**: 60 FPS target with auto-downgrade mode for low-end devices.
